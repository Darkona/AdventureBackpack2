# Gear

The smaller items of the mod: boots, a machete, a hat, and the campfire and sleeping bag that make a camp. The backpacks, the hose, the crossbow and the flying packs have their own pages.

## Piston Boots

| | |
|---|---|
| Type | Boots |
| Obtained by | Crafting |
| Config section | `pistonboots`, `enabled.pistonBoots` |

> Screenshot: the crafting table with the Piston Boots recipe. File: images/gear-1.png

Wearing them you:

- step up full blocks while sprinting, without jumping
- get Speed I while sprinting
- jump a little higher, with a piston sound
- take no damage from falls shorter than 8 blocks

They give 2 armor points, like iron boots.

The step height, the speed and the fall distance are in [Configuration](Configuration#piston-boots-pistonboots).

## Machete

| | |
|---|---|
| Type | Tool |
| Obtained by | Crafting |
| Config section | none |

> Screenshot: the crafting table with the Machete Handle recipe, then the Machete recipe. File: images/gear-2.png

The machete is made of two iron ingots and a Machete Handle, and the handle has its own recipe.

It cuts through plants fast: leaves, grass, flowers, cobwebs, pumpkins, melons, mushrooms, cactus, cocoa, sugar cane, lily pads, hay bales, wool and crops. It also shears leaves, grass and vines the way shears do, so you get the blocks themselves.

## Campfire and sleeping bag

| | |
|---|---|
| Type | Blocks |
| Obtained by | Campfire: crafting. Sleeping bag: deployed from a placed backpack |
| Config section | `enabled.sleepingBag` |

> Screenshot: the crafting table with the Campfire recipe. File: images/gear-4.png

To make a camp:

1. Place a backpack on the ground and open it.
2. Press the sleeping bag button. The bag unrolls next to the backpack, if there is free space and solid ground for it. You get a chat message if it does not fit.
3. Place a Campfire within 8 blocks of the bag.
4. Right click the bag to sleep.

> Screenshot: a placed backpack with the sleeping bag unrolled and a campfire next to it, at night. File: images/gear-5.png

After you wake up in the bag, if you die you respawn at the campfire you slept next to. If you sleep in a normal bed, the usual bed rules come back. Press the same button in the backpack window to roll the bag up again. If you pick up the backpack, the bag rolls up with it.

The Sleeping Bag item you craft is only a component of the Standard backpack recipe. It cannot be placed on its own.

## Inflatable Boat

| | |
|---|---|
| Type | Item |
| Obtained by | Creative tab |
| Config section | `inflatableboat`, `enabled.inflatableBoat` |

There are two: the Inflatable Boat and the Motorized one. Right click on water to put one down. Its top speed is the same as the vanilla boat by default and can be raised in [Configuration](Configuration#inflatable-boat-inflatableboat).
